Regridding Interface

regrid!(dst_field, regridder, src_field) is one sparse matrix-vector product between two fields whose layouts the package may not know: an extension's field type, a view, an N-dimensional array with a spatial axis. The call decomposes into five seams, each dispatched on the type that knows the answer, so a field type plugs in by extending only the seams it needs.

stepseamdispatches ondoes
1extract_source_arraylike(src_field, regridder; kwargs...)the source typereturns what mul! reads from: the field itself when it is a DenseVector or a contiguous view, regridder.src_temp otherwise
2extract_dest_arraylike(dst_field, regridder; kwargs...)the destination typereturns what mul! writes to, likewise with regridder.dst_temp
3initialize_regridding!(regridder, src_field, src_arraylike; kwargs...)the source typeloads src_field into src_arraylike when they differ
4perform_regridding!(dst_arraylike, regridder, src_arraylike; kwargs...)both arraylike typesthe sparse mul!
5finalize_regridding!(dst_field, regridder, dst_arraylike; kwargs...)the destination typeloads dst_arraylike back into dst_field and divides by the destination areas (normalize = true)

Steps 1 to 3 and 5 see the field types; step 4 sees only the arraylikes, so the fast path (a dense source into a dense destination: one mul!, no copies) is selected by the arraylikes alone, and a field type never has to know what the other side is. Developer notes explain why the seams are cut here.

N-dimensional fields

A StridedArray with more than one dimension is regridded along the axis dims (default 1), the other axes iterated: the extractors wrap it in an NDSliceLoop, an AbstractDimensionalSlicer, and perform_regridding! runs each pair of 1-D slices through the pipeline above. An extension with its own layout subtypes AbstractDimensionalSlicer and returns it from its extractors.

ConservativeRegridding.AbstractDimensionalSlicer — Type
AbstractDimensionalSlicer

A marker for the regridding pipeline that the field should be processed in 1-D pieces. perform_regridding! dispatches on this type and iterates slice_views(slicer), running the standard pipeline on each (source, destination) slice pair.

Interface

A concrete subtype MySlicer <: AbstractDimensionalSlicer must implement:

methodreturnssemantics
Base.parent(::MySlicer)AbstractArraythe underlying field data
slice_views(::MySlicer)iterator of 1-D arraylikeseach element is something mul! can read from / write into

Contract

  • Source and destination slicers in a single perform_regridding! call must produce iterators of equal length, paired by position.
  • Each yielded slice must be a 1-D AbstractVector subject to the existing 1-D dispatch (DenseVector / FastContiguousSubArray fast paths, AbstractVector slow path).
  • The slicer owns the data; initialize_regridding! and finalize_regridding! for slicers are no-ops because each slice is a view into the underlying field.
  • Built-in slicers must fail loudly when the source/destination slice counts or non-spatial axes differ. Do not rely on zip truncation semantics.

Built-in implementations

  • NDSliceLoop — slices an N-D StridedArray along a chosen dimension.

Defining a custom slicer

struct MyMatrixSlicer{A<:AbstractMatrix} <: ConservativeRegridding.AbstractDimensionalSlicer
    array::A
end

Base.parent(s::MyMatrixSlicer) = s.array
ConservativeRegridding.slice_views(s::MyMatrixSlicer) = (vec(parent(s)),)

ConservativeRegridding.extract_source_arraylike(src::MyMatrixField, r; kwargs...) =
    MyMatrixSlicer(rawdata(src))
ConservativeRegridding.extract_dest_arraylike(dst::MyMatrixField, r; kwargs...) =
    MyMatrixSlicer(rawdata(dst))

ConservativeRegridding.slice_views — Function
slice_views(slicer::AbstractDimensionalSlicer)

Return an iterator yielding 1-D arraylike views into the slicer's data. Each view must be acceptable as the source/destination of a 1-D regrid! pass. Required by the AbstractDimensionalSlicer interface.

source
ConservativeRegridding.NDSliceLoop — Type
NDSliceLoop{Dim,N,A<:StridedArray{<:Any,N}}

Built-in AbstractDimensionalSlicer for N-D strided arrays. Iterates 1-D views along all axes except Dim, in column-major order over the other axes.

Constructed automatically by extract_source_arraylike / extract_dest_arraylike when the input is a StridedArray{T,N} with N ≥ 2; not intended for direct user use.
